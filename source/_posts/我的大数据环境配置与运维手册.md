## 2. 安装路径与目录分布

集群软件主要分布在 `/usr/local` 和 `/opt` 目录下。

- **基础底座 (/usr/local)**
    - **Hadoop:** `/usr/local/hadoop` (配置文件位于 `/etc/hadoop`)
    - **Zookeeper:** `/usr/local/zookeeper-3.8.0`
    - **Spark, Kafka, HBase, Phoenix, Sqoop, Flink, Solr, Atlas:** 均位于 `/usr/local`
    - **JDK:** `/usr/local/jdk1.8.0_361`

- **应用组件 (/opt)**
    - **Hive, Flume, DataX:** `/opt/module`
    - **Azkaban:** `/opt/software/azkaban`

## 4. 核心架构配置

### HDFS 高可用 (HA)
- **集群名称:** `mycluster`
- **NameNode:** `master` (Active), `slave1` (Standby)
- **ZKFC 监控:** 通过 ZooKeeper (`master:2181,slave1:2181,slave2:2181`) 实现自动故障转移。
- **JournalNode:** 运行在 `master`, `slave1` 等节点，端口 `8485`。

### YARN 高可用 (HA)
- **ResourceManager:** `master` (rm1), `slave1` (rm2)
- **状态存储:** 使用 ZooKeeper (`ZKRMStateStore`) 进行状态恢复。

### HBase 分布式模式
- **Rootdir:** `hdfs://mycluster/hbase`
- **ZK Quorum:** `master,slave1,slave2`

## 5. 常用运维命令速查

### 启动顺序建议
为了保证依赖关系正常，建议按以下顺序启动：
> **Zookeeper -> Hadoop (HDFS/YARN) -> HBase -> Hive (Metastore/HS2) -> Kafka -> Flume -> Flink -> Solr -> Atlas**

### Hive 服务管理
**启动 Metastore**
```bash
cd /opt/module/hive/bin
nohup hive --service metastore > /tmp/hive_metastore.log 2>&1 &
# 查看状态
ps -ef | grep HiveMetaStore
# 关闭
kill <进程号>
```

**启动 HiveServer2**
```bash
# 杀掉旧进程
ps -ef | grep HiveServer2 | grep -v grep | awk '{print $2}' | xargs kill -9
# 启动新服务
nohup hive --service hiveserver2 > /opt/module/hive/logs/hs2.log 2>&1 &
# Beeline 测试连接
beeline -u jdbc:hive2://master:10000/数据库名 -n hadoop
```

### Azkaban 调度器管理
```bash
cd /opt/software/azkaban

# 1. 启动 Executor Server
cd azkaban-exec
./bin/start-exec.sh
# 激活 Executor (重要)
curl -G "master:12321/executor?action=activate" && echo

# 2. 启动 Web Server
cd ../azkaban-web
./bin/start-web.sh

# 关闭顺序：先关 exec，再关 web
./bin/shutdown-exec.sh
./bin/shutdown-web.sh
```

### Kafka 管理
使用自定义脚本一键启停：
```bash
# 脚本位于 /home/hadoop/bin/kf.sh
kf.sh start
kf.sh stop
```

### Flink 管理
```bash
cd /usr/local/flink/bin
# 启动集群
./start-cluster.sh
# Web UI: http://master:8083
```

### Solr 管理
```bash
# 使用 solr 用户启动
sudo -i -u solr /usr/local/solr/bin/solr start

# 查看服务状态
sudo -i -u solr /usr/local/solr/bin/solr status

# 停止服务
sudo -i -u solr /usr/local/solr/bin/solr stop

# 查看 8983 端口监听情况
netstat -anp | grep 8983
```

### Atlas 管理
```bash
cd /usr/local/atlas

# 启动 Atlas
python2 bin/atlas_start.py

# 停止 Atlas
python2 bin/atlas_stop.py

# 查看 21000 端口监听情况（启动大概2分钟），账户密码均为admin
netstat -anp | grep 21000
```

### Hadoop HA 手动维护
**手动主备切换 (Failover)**
```bash
# 将 master 切换为 Standby，强制 slave1 成为 Active
hdfs haadmin -failover master slave1

# 查看 NameNode 状态
hdfs haadmin -getServiceState master
```

### JDK 版本切换
```bash
sudo alternatives --config java
sudo alternatives --config javac
```

### 网络与进程检查
```bash
# 查看端口占用
netstat -anp | grep <端口号>

# 查看特定进程
ps -ef | grep <进程名>
```
